Base central de respuestas

Para consultar las mismas respuestas en tu celular y computadora, los datos deben sincronizarse con la base central de este sitio. Introduce la misma clave de sincronización en ambos dispositivos. Esta clave debe configurarse también como variable privada VOZ_SYNC_TOKEN en Netlify. No es la contraseña de PostgreSQL y nunca debe escribirse dentro del HTML.

Los registros de otros dispositivos aparecerán aquí después de configurar la función y cargar la base central.
